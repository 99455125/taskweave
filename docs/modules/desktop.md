# 桌面UI与交互

## 职责划分

NiceGUI/pywebview保留为当前UI框架。desktop负责控件、布局、渲染、定时器及平台行为；presentation负责普通状态与交互决定；DesktopController转接应用操作、共享编写请求和平台适配。页面不直接访问仓储或SQL。

| 交互 | 普通状态/流程所有者 | 实际适配 |
| --- | --- | --- |
| 路由、离开选择、标签页草稿恢复 | WorkspaceNavigation、TaskWorkspace、TaskTabTransition、RecoveryState | Workbench、TasksPage、launcher |
| 任务/步骤编辑、保存与批量操作 | TaskDraft、EditorSession、StepActions | TasksPage、StepEditor、StepList |
| 规划配置、候选与导入 | PlanningInteraction、PlanEditorSession | PlanningPage及采集/生成视图 |
| AI选择、生成/修复候选 | AIInteraction、AIChoiceDraft、AuthoringFlow | StepAIEditor |
| 采集草稿、目标、录制提交 | CollectionForm、TargetSelection、ContextCaptureDraft、RecordingDraft | 步骤/规划采集组件、RecordingControls |
| 调试、正式创建、补参 | DebugInteraction、TrialInputDraft、RunCreation、RunInputs | StepDebugPanel、RunPage、RunInputDialog |
| 执行查询、按需/增量日志 | ExecutionInteraction、PollingState、HistoryLoadState、LogStreamState | ExecutionDetails、HistoryPage、LiveRunLogs |
| 分类、筛选、环境和设置 | CategorySession、CatalogFilter、PluginSelection、EnvironmentSession、SettingsSession | 对应页面与控件事件 |

这些对象位于[presentation](../../src/taskweave/presentation)，UI对象留在[desktop](../../src/taskweave/desktop)。未来替换UI需要新适配器，不需要复制交互规则；当前没有第二套UI或远程前端协议。

## 生命周期规则

输入事件及时写入普通草稿，业务动作消费草稿，不在提交时扫描控件树。异步响应检查任务/步骤/运行、版本及视图代次，旧响应不能修改新目标。控件存活与文档可见性由框架观察并传入，交互层决定是否刷新和接纳。

dispose释放自己拥有的计时器和控件资源、使在途视图响应失效；它不改变真实文档可见性，不终止后台运行，也不取消已接受写入。UI重绘不能重新创建业务请求或清除共享在途状态。

同一标签页的步骤/调试/补参普通草稿可在服务内缓存恢复，标签页相互隔离；恢复保留原expected_hash，其他窗口修改时继续报冲突。缓存不承诺服务重启或标签页关闭后恢复，规划/环境表单和未提交AI弹窗不属于这一标签页恢复范围。

## 页面与平台

规划侧栏将分类管理和新建操作与标题放在同一行。共享主题为输入、选择、数字和多行文本控件统一提供16px左右内边距；紧凑浮动标签控件保留标签与值的纵向空间，多选及多行控件随内容增长，不受单行固定高度约束。

规划详情分为目标与要求、上下文材料、生成记录。环境与多插件选择位于目标与要求，插件使用同排紧凑复选项并随宽度换行，保留原有多选值与显式保存；已选但当前未安装的插件仍显示实际状态并可取消；顶部生成任务先保存草稿，再选择 API 或网页 Chat，渠道窗口展示当前修订、所选插件及上下文组数。目录与标题显示真实修订，复制和删除位于更多菜单。候选摘要和历史集中在生成记录，历史显示生成时冻结的材料修订与真实导入次数；导入次数仅为已有导入标记的记录读取回执，并按记录更新时间缓存，失败后保留旧表格且允许重新加载；候选弹窗展示步骤概览、可展开的代码与材料及实际导入回执。保存及上下文更新后原位同步页眉和目录的名称与修订，不重建编辑器；能力加载失败保留基础字段和生成记录，并提供原位重试。

规划/步骤采集、录制、环境切换及步骤离开的丢弃确认框统一使用紧凑标题、后果说明和右对齐操作区；继续编辑为中性按钮，丢弃为浅红底红字，保存为蓝色主按钮。

顶部主导航的图标与文字间距统一为6px，清除按钮图标自带的外边距；宽屏菜单项之间保留4px间隙。未选中项的图标和文字使用品牌蓝，悬停显示浅蓝底；选中项使用品牌蓝、浅蓝底和轻微阴影。

规划与步骤分别组装采集弹窗，共用采集项列表、录制控件与草稿处理。两处均在上下文名称与操作说明之后，按采集项列表、录制/采集按钮、采集参数的顺序排列；录制与采集按钮横向排列，新采集项追加到底部并滚动至新增项，取消与确认保存位于独立底栏。采集卡片以普通标题和来源摘要显示，标题及操作说明在卡片内编辑；新采集页面优先使用实际页面标题。网址与右侧“编辑说明”共用一行；操作说明为空时不创建额外正文行，存在内容时再在下方展示。待删除列表为空时隐藏，避免叠加列表与采集按钮间距。采集参数使用框外标签和42px单行控件；字段顺序、行与宽度比例读取插件请求Schema的`x-taskweave-context-form.rows`（见[插件契约](../contracts/plugins.md#采集表单布局)），规划与步骤使用同一渲染器，不按插件ID或参数名分支。Playwright声明两行，TiDB等简单采集器声明一行，数组/对象按插件声明单独占行；窄屏统一改为单列。未声明布局的旧插件自动排版。字段说明通过控件悬停提示提供；同时生成预览随当前采集器放入参数网格，高级参数为轻量折叠行。预览按钮与“携带预览”勾选项相邻，勾选项仅位于采集卡片，预览弹窗只读；没有预览素材时禁用勾选。

已保存的材料也使用紧凑采集项：标题与预览操作同排，时间来源和编辑说明同排，正文只显示已有说明。组操作靠右，空组说明不占位；原始证据通过预览查看，无预览回调的调用者继续保留摘要。携带预览的异步更新检查所属页面仍然有效。

常驻界面删除暂存机制、内部存储和操作教学等说明段落，不改写为缩短提示。保留字段契约说明、用户内容、实际错误、运行状态和必要的操作确认。

Workbench显式装配Home、Tasks、Planning、Executions、History、Plugins、Environments、Settings和Marketplace等页面。StepEditor组合步骤、AI、调试和上下文；窄面板协作，避免将整个Workbench作为任意服务代理。

对话框支持ESC和点外关闭，共享捕获守卫阻止穿透；不要给普通弹窗加persistent/no-esc-dismiss。文件选择、剪贴板、打开路径及原生窗口在desktop/platform.py等适配；浏览器调试模式与原生窗口模式分别验证。

首页“新建执行”直接打开任务选择与运行配置窗口，创建成功后进入执行页；最近执行结果通过“全部记录”进入执行页。任务行的“新建执行”继续预选该任务。

## 步骤工作区

步骤管理顶部为横向流程画布，展示现有 action、if、foreach 和 loop。节点选择、添加、移动和确认继续使用现有流程契约；条件与循环在画布下方配置，未保存配置切换时提供保留、丢弃或保存选择。

步骤与任务组合条件编辑均提供“允许并行”。关闭时按顺序执行首个匹配，开启时冻结全部命中路径并执行，零命中走唯一“否则”。新条件保存为带稳定分支 ID 的 cases/default 结构，排序同时移动条件、路径和公共输出；新增分支须明确配置已有公共输出，非空分支先移走节点后才能删除。完整流程仍经过深度、作用域和引用校验。并行汇合后才继续后续节点；并行路径使用独立资源会话，首个匹配模式沿用当前会话。

步骤编辑分为基础配置、步骤代码、输入输出、上下文和调试。基础配置保留描述生成与紧随描述的步骤说明；多插件选择、动作辅助和代码生成集中在步骤代码页。代码与调试复用同一个编辑控件和草稿，重绘保留当前步骤的编辑页签。调试结果按对应尝试的 execution_path 读取，避免将单步调试或循环单轮误当成整个流程聚合结果。

调试使用同一编辑面板的全宽标题和页签。环境、状态及开始/结束操作位于顶部工具栏，调试输入与运行记录可分别展开；代码和日志位于主栏，AI 修复要求、上次结果及清空上下文入口位于辅助栏。窄窗口按单列排列。打开/收起调试或切到控制配置再返回，复用已构建的输入、代码和补充要求控件，不隐式保存。AI 修复继续使用既有依据与渠道弹窗，候选审阅内联于代码工作区。流程收起与缩放状态按任务保留在当前界面会话，整页重绘后恢复，不写入流程定义。

编辑区标题展示步骤序号、名称和画布中的实际分支/循环路径。代码页顶部集中插件多选、插入动作与 AI 编写入口；动作参数与 AI 编写共用可切换、可收起的辅助区，收起后代码扩展至整行。切换复用同一控件和草稿，当前步骤的辅助区选择在重绘后保留；窄窗口按单列排列，调试页隐藏此辅助区。

动作列表按当前多选插件过滤；动作辅助读取动作的 input_schema，使用框外标签和自适应紧凑网格；对象与数组占完整行。字段类型、默认值和必录校验沿用 ValueForm，参数变化实时更新调用代码预览。插入读取编辑器当前文档和光标，按光标所在逻辑语句的起始行和缩进插入完整调用，多行字符串与括号表达式不会被拆开，保留已有返回语句；异步读取后核对当前步骤和代码，过期响应不能覆盖新草稿。插入成功自动加入对应插件，预览不修改代码或插件。

调试侧栏内联展示生成渠道、本轮要求、历史范围和精简重复字段选项，复用既有修复请求及候选采纳链路。失败依据绑定实际运行与尝试，实际执行代码、失败动作、快照可分别勾选携带并只读查看；没有失败依据时仍可生成修复建议，依据当前代码、已采集上下文和本轮要求修订；历史会话按所选范围携带。侧栏实时比较失败代码与当前草稿；请求前重新获取并核对运行/尝试，记录已变化时要求重新核对，避免使用旧依据。旧调用方的渠道弹窗入口继续保留。调试记录下拉读取当前步骤的历史运行，切换后使用所选运行查看日志、结果和修复依据，不改写代码草稿；运行快照以真实定义版本标识，可展开查看。选择仅查询和切换当前调试上下文，不启动、结束或修改运行，原继续/结束操作仍作用于当前所选记录。


输入输出页分别展示输入 Schema、输入来源绑定和输出 Schema。两种 Schema 均支持字段表单及高级 JSON；复杂类型、联合或引用默认使用 JSON 保留完整定义。字段表单与 JSON 切换同步当前内容，非法 JSON 或 Schema 阻止保存并保留原文；两种编辑方式、字段及未完成 JSON 均随当前标签页草稿恢复。输入 Schema 默认只要求对象，输出 Schema 默认 {}，无改动时保持原定义。输入字段 default 属于原步骤输入解析；输出 Schema 的 default 是描述信息，不自动补充 ctx.result(data=...) 返回数据。输出 Schema 修改沿用原 expected_hash 和步骤确认失效链路。输入来源绑定保留固定值、任务参数、环境配置、前序结果、循环变量和分支公共输出。参数类型选择保留足够宽度；绑定卡片使用统一浅边框与自适应字段网格，固定值隐藏整个引用字段和投影行，前序结果继续显示逐轮投影与所属循环。来源切换复用原控件和值，字段解析、作用域校验和运行读取规则不变。

步骤代码页内嵌 AI 编写区，选择 API 或网页渠道并填写本轮要求，沿用现有生成请求的 repair_notes 字段。生成继续携带已保存的当前代码、描述、说明、所选能力和上下文，没有新增“不携带当前代码”后端选项。本轮渠道和要求按步骤保留于当前编辑会话，页面重绘不清空；不承诺服务重启恢复。

代码页和调试区均提供上次 AI 结果入口，首次请求后无需重绘即可恢复。API渠道恢复保留的候选，不重新生成；网页渠道恢复导出请求，未采纳的粘贴回复关闭后不保留。这些请求结果属于当前应用会话，不承诺服务重启恢复。API 与网页候选共用内联代码对照和差异视图，辅助区显示解释、诊断、版本及采纳操作；650px及以下对照使用单列。网页解析后关闭导出弹窗，返回修改时保留本次回复；舍弃恢复原代码控件。采纳仍经过请求身份、版本与执行证据检查。“仅采纳”保存并重绘；“采纳并调试”先保存，再打开同一调试面板并调用既有调试入口，沿用环境、输入和重复写入确认。保存失败不启动；调试启动失败保留已采纳代码并明确反馈；保存期间切换步骤或产生更新草稿时不误启动或覆盖新草稿。网页步骤描述导出的提示词固定8行、内部滚动，复制仍取得完整文本。

任务工作区顶部保留当前任务的分类选择与收藏。窄窗口将长标题和操作栏分行显示，操作按钮按可用宽度换行，避免标题被挤成逐字竖排。分类管理、分配及删除后原位更新目录标签、筛选选项和当前分类，不重建步骤编辑控件；未保存的步骤草稿继续保留。任务删除及运行清理使用统一的右侧取消和危险操作确认布局，清理范围沿用现有命令。

## 任务组合工作区

组合编辑外层分为任务编排、基础配置、运行历史；任务编排内为结构化流程画布，可插入条件分支、列表遍历与条件循环，并将任务移动到指定路径；下方任务节点编辑分为任务配置与输入映射，控制节点显示条件、遍历列表或循环状态配置。页头执行组合打开启动输入弹窗，取消保留本次输入草稿，执行仍使用原保存、预检与启动链路，成功创建后切到当前组合历史。运行历史默认筛选当前定义，全部组合选项保留跨组合及已删除定义的历史查看能力；未选择组合时显示全部记录。选中节点按 node_id 保持身份，移动和重复引用同一任务均保留节点独立环境与输入。节点及添加任务摘要显示实际步骤数，确认状态同时检查步骤验证状态与流程确认；不替代执行前的后端预检。任务节点仍引用已有任务；同一任务在不同引用、分支或轮次执行时保持独立实例。

组合与步骤画布共用顶部“添加节点”、空路径添加、节点菜单前后插入及拖动落点；节点之间保持连接线，拖动时才显示落点。组合节点菜单提供“移除任务”，只移除引用；移动以流程树内相邻节点及目标路径为准，任务引用顺序随结构更新，保留独立环境、映射和未完成的 JSON 文本。插入或移动后选中新节点或移动节点，删除后保留有效选择，非法依赖移动或删除保留原结构并显示失败原因。组合控制配置同步到草稿，保存仍检查现行任务确认与组合业务规则。

两处画布分别显示业务节点数与控制节点数，使用“列表遍历”和结构路径提示；75%、100%、125% 缩放与收起状态按当前会话的任务或组合保留，操作栏随窄窗口换行。零步骤任务保留真实可编辑画布，可先建控制结构，再从空路径插入步骤；控制配置离开时仍执行原保存、丢弃或继续编辑规则。执行详情继续使用只读画布。

输入映射支持固定值、组合启动输入、结构上可用的前序任务输出、当前循环变量、分支公共输出及逐轮投影；未完成的 JSON 固定值在节点切换时原样保留，修正前阻止保存。运行区继续调用原组合运行命令，数据未变化时保留控件，避免轮询重建中断选择与点击。

组合历史显示实际调用路径和轮次，补参、失败重试和结果核对绑定组合 execution_path 与子运行，使用紧凑弹窗，取消不提交；重试默认选最后一个有效失败步骤，核对列表仅显示有效尝试及冻结步骤名称。非终态组合提供既有取消命令入口；取消与资源释放仍按既有后端规则处理。

删除组合运行先显示统一危险操作确认，展示冻结组合名称和运行编号；取消保留记录，确认绑定弹窗打开时的运行身份，沿用既有子执行及结果清理命令。

子执行详情使用冻结任务名称、运行环境、时间和步骤尝试组织可读摘要；任务输入、原始运行数据按需展开。每条保存结果按 result_id 打开，不用当前任务或最新尝试替代所选运行的结果。

## 执行详情

执行详情按执行进度、日志、结果、输入、执行快照分区。历史尝试位于进度下方，结果使用有效尝试及其明确身份；输入展示存储的摘要。日志区域独立于状态轮询重绘，切换页签保留日志控件与增量游标。执行快照先展示冻结的任务和步骤，步骤代码按需展开，完整原始定义和插件版本仍可查看；不读取当前编辑稿替代运行时版本。

执行进度与步骤管理共用 FlowTree 画布，按运行快照中的流程结构展示开始、结束、顺序连线、条件分支及循环返回路径。执行画布只读，步骤可选择并查看结果或错误；没有 flow 的历史快照按快照步骤顺序展示。动作节点保留执行状态，条件/循环流程明确标注最近一次有效尝试的状态及次数，流程路径与逐轮结果继续保留；未执行节点不推断为成功。长路径在画布内部滚动。实际路径由 presentation/execution_paths.py 基于有效动作尝试、execution_path、控制选择和轮次记录投影，蓝色表示已走过的连线，灰虚线表示未命中或未进入，浅色表示尚未执行或尚未判定；分支入口与出口分别依据记录标记，失败后及判定失败时不补造路径。多轮汇总展示已记录轮次的命中与未命中次数，可通过“路径轮次”查看对应循环及嵌套路径。轮次视角下节点的结果和错误绑定该视角内的实际尝试；下方步骤详情、历史、执行操作、日志、输入和快照保持完整运行语义。

新建执行切换任务时，开始步骤控件的程序更新不重复触发参数区渲染，保留单份输入草稿。包含条件或循环的任务固定显示“启动范围：完整流程”，presentation 的 RunCreation 提交时不传线性开始步骤；线性任务继续允许选择开始步骤。两者均沿用原有任务输入、步骤输入与运行命令，后端流程执行规则不变。结果核对入口仅在后端允许的中断或失败运行中展示；弹窗使用全宽结果选择和紧凑说明，选择结论后才能保存，取消不提交。已结束运行保留原尝试与错误供查看。

## 验证定位

设置页的 Skill 导出目录与工作空间迁移目录分别绑定控件；导出仅写所选目录，沿用已有冲突保护与重复导出判定，不改动用户全局 Skill 目录。

对应ui.*及presentation.interactions。无GUI导入测试证明普通交互可运行，实际NiceGUI事件测试证明接线，真实浏览器验证页面装配；三者覆盖含义不同。启动与包资源见[运行与打包](../deployment.md)。

网页 Chat 的步骤代码请求与修复请求共用内联提示词/附件/回复区，左侧保留当前代码控件；解析后切换到候选对照，返回修改继续保留原回复。复制、附件预览、JSON解析、版本及失败证据校验、调试会话追加均沿用原有调用；没有工作区挂载的旧调用方继续使用原弹窗。


## 网页 AI 文件导出

步骤代码、步骤描述及规划的网页 AI 导出共用紧凑文件区，仅显示“预览文件”和“下载全部（ZIP）”。文件预览以选择器切换完整对话、消息 JSON 或图片，不逐项显示下载按钮。ZIP 包含完整 UTF-8 对话 conversation.txt、原导出包含消息记录时的 messages.json，以及全部所选图片附件；保留提示中的附件文件名，沿用 send_preview 选择和已有脱敏规则，不重新调用模型。无图片时仍能下载对话。浏览器直接下载 ZIP；本机模式沿用 exports 目录的独立文件及打开目录行为。

共享流程画布的连接线同时声明实际宽度与 flex 占位，使 WKWebView 的 max-content 测量包含线段；结束标记跟随完整流程内容，横向滚动和缩放时不覆盖末尾卡片。
