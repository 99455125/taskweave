## 功能核对

[完整功能映射与缺口](feature-coverage.md) 将当前桌面功能分为 72 组，逐项记录源码、目标入口和覆盖状态。依据 33 份 desktop Python 文件及 450 处控件/操作引用；[源码盘点 JSON](source-inventory.json) 是追溯证据，日常无需加载整份。

- **调试补齐**：当前步骤、从选定步骤调试到当前步骤、结束调试；环境/任务/步骤三层输入；缺参补录；尝试与结果、打开失败步骤、报错证据移除；API/Chat 修复、历史轮数、去重、补充说明、清空 AI 修复上下文。
- **上下文纠正**：上下文组 + 有序采集项；名称说明、提供方、会话与目标、schema 参数/高级 JSON、预览开关；连续采集暂存、项标题/排序/删除撤销；确认整组保存与取消丢弃；AI 证据和用户预览分开。
- **编辑补齐**：代码编辑器、多插件、步骤补充说明、AI 生成描述、动作表单、变量和依赖、时间设置、内容校验、确认验证、步骤管理与一键确认；调试历史独立于正式执行历史。
- **其他页面补齐**：规划候选与生成记录、导入导出、执行至此/重跑/核对、插件状态与契约说明、环境变量、AI/隐私/并发/工作空间设置、市集占位、实例管理和服务日志。

“入口可达”不等于原型已完整执行该功能。真实动态 schema、renderer、排序分页、文件打开、保存并发、资源生命周期、倒计时、异步响应隔离和业务校验仍是产品接入任务。当前原型不替代业务回归。

## 交互组织

宽窗口统一左搜索列表、右详情；步骤目录位于任务内部，调试区可收起。中窗口将调试区移到表单下方，窄窗口把主列表移到上方。代码、日志和步骤轨道在自身区域滚动。

执行轨道用小节点和细线表达顺序；浅蓝背景是当前查看，文字/颜色是运行状态。节点只查看，原有运行能力放在“执行至此 / 重跑”弹窗中，保留三种范围选择。真实可用性由当前有效尝试、前序条件、can_end 和外部结果决定，不能仅按按钮颜色决定。

复杂交互放在明确命名的弹窗，避免将全部按钮挤在主界面。上下文编辑取消不保存；示例连续采集与删除撤销可实际体验。调试的“清空 AI 修复上下文”与“结束调试”分开，防止误解其影响范围。

## 待确认与排除

收藏/分类已授权，任务侧先给单层单分类候选；规划范围、层级、删除归属、复制分享携带规则仍待确认，不修改任务包。工作台统计口径和活跃资源范围需映射真实数据。

插件安装升级、账号按用户要求排除。插件独立使用统计/诊断日志、全局搜索、通知、配额、其他执行器和自动重试不因原图出现就当作现有功能。市场保持建设中。结果页签只在真实结果声明相应 renderer 时出现，本原型全部类型页签仅用于审阅布局。

## 原型文件边界

- [app.py](app.py)：外壳、工作台、任务/步骤、执行。
- [widgets.py](widgets.py)：共享样式控件与示例数据。
- [secondary_pages.py](secondary_pages.py)：规划、插件、市集、环境、设置。
- [detail_dialogs.py](detail_dialogs.py)：调试、上下文、AI、任务操作与运行等详细交互。
- [style.css](style.css)：公共视觉与窗口适配。

正式接入应沿用产品已有页面/组件和控制器边界，不把本原型作为新的业务层直接复制。此前产品源码中未完成的改版和两个执行选择测试仍按当前状态记录，本轮不将它们标为通过。

## 第二版细节修订（用户审阅后）

- 其余整体设计已获认可。规划第二页签统一为“能力与上下文素材”，配置页不再重复素材。
- 调用入口统一为“大模型api调用”“大模型网页chat调用”。
- 规划候选保留，侧栏在结束采集实例上方增加“导入为任务”；可重复进入。用户已确认每次导入创建独立新任务，保留候选与冻结上下文；现行核心返回原任务的行为须在正式接入时调整。
- 插件页读取静态 [契约快照](plugin-catalog.json)，覆盖四个插件的全部 25 个动作及声明的采集能力；逐项展示用途、参数、返回值、执行约束、调用示例。未声明的说明明确标示，不编造契约。快照只用于设计预览，产品接入须读取实时已安装插件。
