# REQ-006 设计边界

模板导入和插件安装是分开的操作，安装受信任插件后才启用。冲突默认生成新任务 ID，显式更新覆盖当前配置，活跃运行时禁止覆盖；历史执行记录保留。依赖清单声明支持的 Python 和系统，不能把单个平台的二进制包宣称为跨平台包。

依赖：REQ-003、REQ-004。实现前阅读 [总设计](../REQ-002-task-plugin-design/design.md) 和依赖需求的已交付契约；本文是实施输入，不代表功能已完成。具体类/字段/消息格式在实施时补齐并记录兼容影响。

## 关键交付

- 带版本的模板 JSON/zip manifest 和资源清单。
- 导出预览、导入检查、ID 冲突和环境角色映射。
- 插件版本和依赖检查，可选携带离线 wheel。
- 无凭据分享、资源路径校验、损坏包错误处理。

## 非目标

不做在线市场和自动从未知来源安装插件。

本需求先验证基础顺序任务分享；后续控制流和图形定义的格式兼容、版本升级与导入导出回归分别由 REQ-008/009 完成，不构成本需求的前置依赖。
