# REQ-006 · 任务分享与离线插件交付

状态：未开始。依赖：REQ-003、REQ-004。

## 目标与范围

- 带版本的模板 JSON/zip manifest 和资源清单。
- 导出预览、导入检查、ID 冲突和环境角色映射。
- 插件版本和依赖检查，可选携带离线 wheel。
- 无凭据分享、资源路径校验、损坏包错误处理。

## 范围边界

不做在线市场和自动从未知来源安装插件。

## 验收标准

- [ ] 导出后在另一独立数据目录导入，任务步骤/参数绑定一致。
- [ ] 缺少插件或版本不匹配时明确阻止执行并列出解决项。
- [ ] 模板包不包含账号、Token、浏览器状态、运行 DB 和绝对本机路径。
- [ ] 压缩包越界路径或损坏资源拒绝导入，不覆盖原任务。
- [ ] 匹配 Windows/Python 平台的离线依赖包可在无公网环境安装验证。
