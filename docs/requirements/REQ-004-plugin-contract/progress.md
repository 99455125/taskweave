### 2026-09-19 TiDB 与任务配置分享

- 可选 database extra 提供 `plugins/tidb`，使用 PyMySQL/MySQL 协议，连接配置读取环境及任务变量，提供连接测试、表结构采集、参数化只读查询和 tidb.table/tidb.verification 展示器。数据库连接每次关闭；API/Chat 共用插件格式，Chat 不假装可以访问数据库。
- 任务列表提供导出 JSON、复制 JSON、下载 JSON，以及粘贴导入为新任务。`taskweave-task-1` 包含任务名称、说明、参数默认值、按序步骤内容/参数/插件要求/绑定；前序依赖通过可移植步骤 key 重映射。环境、历史、文件和执行结果不导出。导入执行静态检查和插件校验，不运行步骤，全部标记 MANUAL/VALIDATED；缺失插件或无效配置拒绝导入，失败不留下半个任务。只支持当前线性步骤配置。
- 环境列表支持确认后删除，保留历史业务结果，历史执行保存 deleted_environment_name 并解除外键；保留资源、运行或暂停中的环境禁止删除。默认环境删除后清除默认设置。环境不提供导入导出。
