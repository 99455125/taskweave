# REQ-009 · 流程图拖拽编排

状态：未开始。依赖：REQ-003、REQ-004、REQ-005、REQ-008。

## 目标

通过拖拽已固化步骤、条件、循环和子任务来定义流程，并直接显示执行状态。

## 范围

- 节点面板只提供已验证可用的步骤及插件动作及控制流节点，连线描述依赖与流向。
- 参数面板显示步骤输入、前序输出、分支条件、循环和子任务配置。
- 流程图和任务定义使用同一个模型，布局坐标单独保存，不维护第二套执行逻辑。
- 保存前校验断开的节点、端口、引用、非法环路和未验证的步骤内容。
- 运行时高亮节点和迭代/子流程状态，可跳转结果与日志；浏览器实际操作仍由 worker 执行。

## 验收

- [ ] 拖拽搭建带条件、循环和子流程的任务，保存重开后语义与布局一致。
- [ ] 列表/图形编辑往返不丢失参数或修改稳定节点 ID。
- [ ] 非法连线、隐式环路、缺少分支出口在执行前给出明确位置。
- [ ] 有活跃运行时不能覆盖其配置；结束运行后编辑保存；嵌套执行可定位具体节点。
