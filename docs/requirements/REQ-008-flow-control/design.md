# 条件、循环与嵌套流程设计边界

按确定的规则选择分支、重复执行步骤、复用子流程，所有控制流执行均可定位、暂停和追溯。

- 条件节点使用受限比较操作符和明确的默认分支，不执行任意代码表达式。
- 循环明确数据集合或条件、迭代变量、最大次数与超时；初版逐项顺序执行。
- 嵌套节点引用子任务 ID，显式绑定输入输出，校验引用循环并拒绝递归。
- 运行中用节点路径、迭代序号、子运行 ID 区分每次执行，支持进入子流程单步查看。
- 非选中分支显示为未选中而非失败；循环失败默认停止，重试不得重做已确认成功的副作用动作。

REQ-002 先定义共享模型边界，本需求再做详细实现。结构化循环/条件/子流程是首版目标；不支持任意连线形成的隐式循环。界面组件选择先通过交互原型验证，不提前固定库。
