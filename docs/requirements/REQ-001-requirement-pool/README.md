# REQ-001 · 总需求池

本目录只负责汇总 TaskWeave 的产品需求、拆分归属、优先级、实施路线和整体验收，不作为独立功能需求。**正式需求从 REQ-002 开始。**

## 入口

- [总需求池](backlog.md)：功能清单、所属需求、优先级与状态。
- [实施路线](roadmap.md)：正式需求依赖与交付里程碑。
- [整体验收](acceptance.md)：第一版完成标准。
- [维护进度](progress.md)、[文档检查](validation.md)。

## 管理约定

工程建立、Git 仓库和 AI 协作基础不属于产品需求；相关历史归入项目级文档。需求实现状态由所属 REQ 维护，完成或变更时同步总需求池。新想法先入池，明确范围后分配独立 REQ。
