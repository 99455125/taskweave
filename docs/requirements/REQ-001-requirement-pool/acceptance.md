# 整体计划验收

当前全部为待执行验收场景，不是验证通过记录。

基础版本在 REQ-007 验收，控制流与图形编排在 REQ-008/009 追加验收。

## 基础版本主流程

- [ ] 新环境安装 TaskWeave 及匹配的 Playwright/业务插件。
- [ ] 导入顺序任务模板，映射本地环境与角色。
- [ ] 输入测试参数，通过已验证的已验证动作创建一张模拟业务单据。
- [ ] 单步完成后浏览器保留，人工检查后继续提交。
- [ ] 导出结果文件，能回溯输入、单号、步骤尝试、日志和截图。
- [ ] 同模板创建第二次运行，状态与数据相互独立。

## 关键异常

- [ ] 重复点击只启动一次有效尝试。
- [ ] 缺插件、版本冲突、参数错误时执行前明确提示。
- [ ] 提交超时/worker 崩溃后标记不确定，不盲目自动重试。
- [ ] 人工已完成提交后，继续操作不会重复做单。
- [ ] 前置步骤重跑后下游结果失效，不能用陈旧上下文继续。
- [ ] 数据迁移、备份恢复与导入冲突均有可验证处理路径。

## 团队交付

- [ ] 分享包不包含凭据、运行数据库或浏览器登录态。
- [ ] 第二台 Windows 匹配依赖后可运行；离线安装实际验证。
- [ ] 用户指南、插件开发说明、已知限制与版本清单齐备。
- [ ] REQ-003 至 REQ-009 的 validation.md 有实际证据。

若未提供真实内网业务环境，真实业务适配作为明确的后续集成项，不能将模拟业务成功写成真实环境通过。

## 步骤固化与流程编排

- [ ] 草稿步骤经试跑与业务断言验证后固化，保存代码版本与验证证据。
- [ ] 修改内容后重新验证并保存当前步骤；活跃运行时不覆盖其配置。
- [ ] 条件选择、循环迭代、嵌套调用可在日志中定位且暂停恢复不重复做单。
- [ ] 拖拽编排和列表编辑使用相同定义，保存重开不丢失语义及布局。
- [ ] 正常运行不调用 AI，不需要 Excel 插件。

- [ ] 无模型配置时能手写内容、试跑并保存；AI 生成后可手动修改。
- [ ] Playwright 通过统一插件接口接入，启停不破坏无浏览器任务，核心无 SDK 依赖。

- [ ] 验证插件结果保存：无数据不建库，表格数据进入当前任务库，文件进入当前任务目录，总库只管理执行记录与结果索引。
