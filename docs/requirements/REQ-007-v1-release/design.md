# REQ-007 设计边界

首发按 Windows 免安装便携目录交付：PyInstaller onedir 加完整 Chromium，解压运行 TaskWeave.exe；禁止安装或下载依赖。核心、UI 与插件版本在发行清单中固定。新数据结构不自动覆盖旧 EXCEL_BASE_DIR，旧数据迁移须备份与显式映射。发布产物只在检查通过后生成，产品验收区别于本地开发测试。

依赖：REQ-003 至 REQ-006。实现前阅读 [总设计](../REQ-002-task-plugin-design/design.md) 和依赖需求的已交付契约；本文是实施输入，不代表功能已完成。具体类/字段/消息格式在实施时补齐并记录兼容影响。

## 关键交付

- Playwright 编排任务端到端示例、回归矩阵与发布检查。
- Windows 解压运行、覆盖升级、移除与离线指南。
- 版本信息、依赖锁定/归档、发布产物和校验清单。
- 本地数据备份恢复、旧工程迁移说明和已知限制。
- AI 项目文档、用户指南和插件开发文档收口。

## 非目标

不把源码能运行视作 Windows 离线安装已验收；不在缺少真实业务环境时宣称真实业务适配完成。

本需求交付基础顺序任务版本；条件/循环/嵌套与图形编排随后由 REQ-008/009 实现和验证。

具体打包清单、WebView2 依赖和干净 VM 验收见 [Windows 打包方案](windows-package.md)。
