# REQ-007 · 基础版本集成验收与发布

状态：未开始。依赖：REQ-003 至 REQ-006。

## 目标与范围

- Playwright 编排任务端到端示例、回归矩阵与发布检查。
- Windows 解压运行、覆盖升级、移除与离线指南。
- 版本信息、依赖锁定/归档、发布产物和校验清单。
- 本地数据备份恢复、旧工程迁移说明和已知限制。
- AI 项目文档、用户指南和插件开发文档收口。

## 范围边界

不把源码能运行视作 Windows 离线安装已验收；不在缺少真实业务环境时宣称真实业务适配完成。

## 验收标准

- [ ] 新环境解压便携包 → 导入示例 → 选择已验证步骤 → 浏览器创建 → 人工检查 → 提交 → 查看结果。
- [ ] 同一模板重复运行互不污染，故障重启和重复点击通过回归。
- [ ] 第二台 Windows 使用自己的角色配置完成同一流程。
- [ ] 备份恢复后任务及历史可读；升级迁移有回滚路径。
- [ ] 发布记录列明实际平台/版本/命令和结果；未执行的验收保持未完成。
