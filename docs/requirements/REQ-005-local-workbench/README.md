# REQ-005 · 任务编辑与执行操作台

状态：代码已交付，52 项回归通过，待用户验收；Windows 实机未验证。依赖：REQ-003、REQ-004。

## 目标与范围

- Windows / macOS 跨平台独立窗口客户端，使用 NiceGUI native mode + pywebview；默认不在系统浏览器打开工作台。

- 步骤编辑页提供目标描述、插件能力选择、AI 生成/修订、step content 编辑、调试日志和验证后保存入口，调用 REQ-003 服务。

- 本地任务列表、新建、复制、编辑、排序和任务参数。
- 插件动作选择与 schema 驱动基础表单。
- 运行选择、单步/到此步/连续/暂停/结束操作。
- 步骤详情、错误、输出、日志、截图和运行历史。
- 本地环境/角色配置、运行前检查和空状态提示。

## 范围边界

本需求交付基础界面；拖拽流程图由 REQ-009 实现并共用任务模型。多人账号权限和云端工作台不在本期范围。

## 验收标准

- [x] 不编辑 JSON 即可创建并运行一个由两种示例动作组成的任务。
- [x] 执行中界面保持响应，多次点击不重复启动。
- [x] 每个步骤显示状态/有效输入/输出/尝试历史和可理解错误。
- [x] 保存修改直接更新任务/步骤；有活跃运行时阻止覆盖配置，历史执行记录保持不变。
- [x] 服务默认仅监听本地地址；macOS 原生窗口启动，协调器 OS 锁与 worker spawn 检查通过。
- [ ] Windows 10 x64 原生窗口与 worker 启停实机验收。

- [x] 任务内二级导航、步骤间隔配置、等待状态与暂停/继续行为。
