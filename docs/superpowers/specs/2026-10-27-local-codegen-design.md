# 插件本地代码生成设计

状态：2026-10-27 用户已确认修订设计与页面样式并授权实施；实现进度见[实施计划](../plans/2026-10-27-local-codegen.md)。

## 目标与范围

录制统一在现有“上下文”入口完成。同一份保存的录制上下文可以用于 AI 编写，也可以用于插件提供的本地代码生成。本次仅 Playwright 提供本地生成能力。步骤代码页保留“插入动作 / 本地代码生成 / AI 编写”并列入口及左侧代码、右侧辅助的布局。

本地生成只消费已录制的上下文，完成材料选择、确定性转换、必要参数补充、预览和应用；不启动浏览器、不提供开始/停止录制、不重新执行录制动作、不调用模型。AI 编写沿用现有上下文材料和渠道逻辑。

生成候选满足 TaskWeave 的步骤入口与动作契约，可以进入现有保存、调试及确认流程；业务验收仍通过调试或人工确认完成。用户最新要求取代上一版独立 Codegen 录制窗口、CLI 子进程管理和原生脚本转换方案。

## 当前实现依据

- [步骤编辑器](../../../src/taskweave/desktop/components/step_editor.py)已有插件选择、插入动作、AI 编写、草稿及代次检查。
- [上下文录制](../../../plugins/playwright/src/taskweave_playwright/recording.py)记录 baseline、operation 和 evidence_missing，操作监听为 click/input/change；目标包含定位证据、frame、页面身份和部分脱敏后的值。该记录不是官方 Codegen 源码。
- [上下文暂存](../../../src/taskweave/presentation/context_collection.py)在停止后分页读取，保存 recording_id、session_id、through、available_after、dropped_count；持久化成功才 ack。
- [元素观察](../../../plugins/playwright/src/taskweave_playwright/observation.py)对敏感值使用 [redacted]，长值可能截断，document_url 去除查询参数，不能从这些材料恢复缺失值或完整 URL。
- [SDK](../../../src/taskweave/plugins/sdk.py)和[扩展协议](../../contracts/plugins.md)有可选录制接口，本次新增独立的可选生成能力，旧插件继续工作。
- [步骤校验](../../../src/taskweave/core/validation.py)要求单一 async def run(ctx, inputs)，外部动作通过明确声明的 ctx.call；[定位器](../../../plugins/playwright/src/taskweave_playwright/locators.py)已有 css/role/label/placeholder/within/frame/nth。

## 方案选择

| 方案 | 取舍 | 决定 |
| --- | --- | --- |
| 已保存录制上下文 → 插件确定性转换 | 复用一份材料，脱离活跃浏览器也能生成；需明确录制语义及缺项 | 采用，符合用户最新要求 |
| 上下文录制同时另存官方 Codegen 原生脚本 | 需要在上下文录制层接入另一套原生录制内部接口并维护版本，不能把现有事件直接交给 CLI | 本次不引入 |
| 本地生成入口另起 Codegen 录制窗口 | 形成第二套录制入口 | 用户已明确取消 |

这里 code generator 指插件的本地转换能力。Playwright 官方 Codegen CLI 用于现场录制，不提供将本项目任意已保存上下文直接转为代码的公开入口。本方案由 Playwright 插件把受支持的结构化录制动作直接生成为 ctx.call，不承诺后台使用官方 CLI。

## 页面与交互

### 上下文入口

录制、暂停、继续、停止、保存及丢弃仍由上下文页面/现有弹窗负责，保存成功后才成为代码生成的数据源。上下文可照常用于 AI 编写；本地生成不会消费、修改或删除它。

### 步骤代码页

沿用用户认可的预览布局。选用支持生成的插件时显示“本地代码生成”；是否显示由插件声明与当前草稿决定，不在宿主写死 Playwright。右侧生成面板包含：

1. “录制上下文”：列出当前步骤保存的、属于所选生成器支持来源的录制材料，展示名称、记录时间、动作数及完整性。
2. “生成代码”：针对所选材料调用本地插件；不打开浏览器。无材料时显示“请先在上下文中录制并保存”，提供“前往上下文”。
3. 生成结果：TaskWeave 代码片段、录制动作、转换问题；“查看完整候选”在左侧只读预览，返回当前代码时保留草稿。
4. 必要补充：缺失/脱敏/截断的动作值或页面地址需要绑定已有输入或明确补充；不得猜测。
5. “插入光标处 / 替换步骤代码”：前者插入动作语句，后者展示完整差异并确认；只更新草稿，不自动保存或执行。

默认选最近一份完整录制，但由用户点击“生成代码”；不自动拼接多份录制。首版每次选一个录制 capture，包含其完整批次；不能只选其中某页 JSON 或悄悄跨录制合并。截图、表结构或普通页面快照仍可用于 AI 编写，本地生成明确提示不包含可转换操作。

保留“① 选择上下文 → ② 预览代码 → ③ 应用草稿”提示。生成面板没有录制、起始浏览器地址、语言环境或启动浏览器的配置。role 从录制上下文的请求/资源角色证据读取；历史材料缺失时由用户在参数补充区明确选择运行角色。

### 草稿与应用

同一份录制可反复生成，AI 编写和本地生成分别产生候选，均通过现有候选采纳与校验流程。一次应用只接纳当前候选；不让两条生成路径互相覆盖。

生成时冻结步骤身份、编辑器代次、源码、插件集合、输入输出 Schema 和源材料摘要。应用前若任一变化，重新预览及校验；材料已删除或修改时阻止旧候选应用。切换步骤后迟到响应不能写入另一页；回到原步骤可恢复本次服务中的候选。

插入复用现有逻辑语句/缩进规则，保留当前 return；替换生成一个完整 run，末尾 return ctx.result(data=inputs)。静态通过只代表入口/动作/参数等已检查，存在 output_schema 时明确提示输出需调试核对，不声称已验证运行结果。

## 可选插件生成接口

新增 core/codegen_contracts.py 和可选 CodeGeneratorProvider，经 SDK 与兼容聚合入口导出；基础 Plugin 协议不新增必选方法，保持 API v1 兼容。

- code_generators()：声明 id、名称、支持的 provider/source、录制格式版本、options Schema 和结果格式版本。
- generate_code(generator_id, recording, bindings, options)：纯转换；不获取活跃资源、不执行外部动作。recording 是宿主从仓储解析的冻结材料，不接受浏览器传来任意源代码。
- 结果包含 source_digest、converter_version、完整 source、body_fragment、required_capabilities、input_slots、diagnostics 和 applicable。
- input_slots 用稳定 slot_id、原始事件序号和参数路径标识值；bindings 指定已有输入引用或允许的常量补充。options 包含已验证的 role 与执行起点选择。
- diagnostics 包含 severity/code、capture_id、事件序号、问题位置和不含敏感值的处理建议。有不支持动作、证据缺失或未解决 slot 时 applicable=false，不返回可执行的残缺流程。

注册表验证声明、方法齐备、标识唯一和 JSON Schema；catalog 新增 code_generators。宿主校验请求和结果结构、动作归属与当前可用能力。单份输入上限 2MiB、1000 个动作、100 条诊断、8 层定位范围；超限整体报错，不以截断材料冒充完整流程。

## 应用与状态分层

- application/codegen.py：step.codegen.sources 列举本步骤的材料；step.codegen.generate 以 capture_id、预期材料摘要、当前步骤草稿、bindings/options 生成与重新预览。同一输入摘要得到相同结果，无需后台录制进程或长寿命会话。
- core/codegen_contracts.py：纯数据与可选接口；不依赖 Playwright、GUI 或模型。
- Playwright 插件 codegen.py：解析录制格式、验证证据、归一化动作并生成 Python AST/source；不跨插件依赖宿主内部仓储。
- presentation/codegen.py：数据源选择、bindings、生成状态、候选与身份检查；状态为 EMPTY/READY/GENERATING/GENERATED/INVALID，GENERATED 不等同于已应用。
- desktop/components/step_codegen.py：表单、源材料摘要、候选预览和事件装配；步骤编辑器组合该组件。
- 仓储沿用上下文组/capture/items；生成候选属于临时编写状态，应用后通过既有步骤保存持久化。

宿主只读取当前步骤拥有的材料，核对 capture/provider/recording 身份和权限；不使用同名材料代替原材料。不扩展计划页面入口、数据库表或任务包版本；新的版本化 JSON 录制项可通过现有上下文保存/导出机制承载，并验证导入后的运行时格式。

## 录制材料与转换可信度

### 当前数据的限制

现有 click/input/change 不必然对应完整可重放的动作：input 与 change 可能重复、checkbox click 与 change 可能重复，后状态可能属于替换后的节点，当前记录也没有显式的导航/按键/业务断言。旧材料只在证据足以确定动作时转换，缺少的值可补绑定；无法确定动作语义时保留 AI 编写用途，并提示重新在上下文中录制。不能把“可用于 AI”直接等同于“可确定性生成”。

### 新录制的必要补齐

在现有上下文录制链路中增加版本化的 playwright.recording 操作表示，保持旧字段和存储兼容；不增加另一套入口。版本项包含 schema_version、recording_id、sequence、page/document/frame 身份、operation、verified_locator、原始事件来源、值状态及证据完整性。

语义归一化在录制器侧完成：同一元素连续文本输入归并为确定的 fill；以元素身份、动作边界和单调序号管理，不凭时间邻近跨控件合并。checkbox/radio 只输出一次明确的设置状态，select 记录单值选择；文本完成事件不能重复生成 fill。未知交互、节点失联、页面切换竞态、额外页面以及不支持手势都写明缺失证据，不能忽略。

录制器还须收集不支持交互的哨兵：至少覆盖非文本编辑的键盘动作（包括 Enter 提交、快捷键及 Tab 焦点切换）、双击、拖放、文件选择、影响交互的 pointer/contextmenu 和容器滚动；它们首版仅形成阻止生成的诊断，不伪装成已支持动作。普通文本编辑由最终 fill 归并，不能因相关 keydown 再生成按键。对 canvas、closed shadow DOM、浏览器内置 UI、跨 context 及无法可靠观察的页面区域明确提示覆盖限制，发现相应证据时不可应用，不将“没有收到哨兵”描述为所有人类行为均已捕获。

暂停/恢复写入明确的区间边界。首版含任何暂停区间的整份录制仅供 AI 编写及观察，不能本地生成可应用候选，避免把暂停期间的登录、导航或编辑当作已录制流程；界面提示重新录制连续片段，不改变现有暂停功能。

上下文停止并排空待处理操作后写入完整性元数据，包含版本、起止序号、结束游标、STOPPED、丢失数及最终校验摘要；分批材料保存为一个 capture，ack 仍只在成功保存之后发生。生成器验证序号、身份、缺失项、截断标志与结束回执；事件分页不改变顺序，重复批次仅在内容一致时去重，冲突或缺口整体阻止应用。旧版 metadata 可读取，但不能伪造新版完成证明。

完整性计数在浏览器各 document/frame 发送之前分配源序号，绑定传输成功才确认；宿主序号仅负责统一展示顺序，不能替代源回执。停止时收集全部参与文档的最终高水位与确认范围。页面跳转/销毁前需要可核对的旧文档封口；绑定失败、文档已丢失无法封口、未知 frame 或待确认事件使该录制不可应用。首版不为导航缺口补造回执；真实导航能否满足封口规则须用 fixture 验证，不能仅凭最后文件或宿主序号连续宣称无损。

生成只使用保存材料；即使原浏览器已关闭也可转换，不回到当前页面重新验证并混入新状态。录制时已验证的定位器不代表未来运行一定仍有效，实际执行沿用插件唯一性与可操作性检查。

### 首版动作与定位

| 录制语义 | 生成动作/条件 |
| --- | --- |
| 明确 click | page_click；排除其只是 checkbox/radio/select 的辅助原始事件 |
| 文本 fill | page_fill；值完整或绑定合法输入，空字符串与缺失分别处理 |
| 单值 select | page_select_option；仅现有 Schema 支持的字符串 value |
| 明确 checked 状态 | page_check；mixed、未知或取消 radio 的非法语义不强行转换 |
| 首版录制不具备的 press/hover/double-click/drag/上传/下载/弹窗/多页 | 报不支持；只在相应上下文录制及生成契约实现后再开放 |
| 页面快照/观察到的状态 | 仅作证据，不自动生成业务断言 |

定位器沿用已验证的 css/role/label/placeholder、frame 和范围结构；不会为本次功能附带新增 text/test_id 或精确文本断言能力。字段存在不代表验证成功，必须核对候选的唯一性、matches_element 和原页面身份。

本次不给上下文录制新增业务断言编辑器；用户需要业务断言时通过现有插入动作、手动编辑或 AI 编写补齐。预览明确显示“已转换操作，未自动添加业务断言”。

### 执行起点与参数补充

录制起始页面属于证据，不自动转成 page_open。默认“继续已有页面”，适合复用前序步骤登录/导航；完整候选开头生成对起始页面已知 origin/path 的 page_assert_url 前置核对，使用精确路径加边界明确的可选 query/fragment 匹配，不能用路径前缀通配误命中其他页面。内部导航不重复 goto，按已录制点击和页面切换证据关联；无法建立因果/同页身份时阻止应用。

用户可明确选择“先打开指定地址”，地址必须由完整录制证据或用户补充/已有输入提供，再生成 page_open。原上下文去掉查询参数的地址只能作为摘要，不能宣称是完整原始地址。没有足够的起点证据时要求用户补充，不能对现有页面随意生成可应用代码。

2026-10-27 用户要求修复新建录制多余空白页和已有会话选页误报非主页面：新建资源复用初始主页面；已有会话的 URL 模式仍新建页面以保护既有现场，选择已有 target 时不导航、不重指向角色主页面。新录制携带 target_mode=primary/selected；所选页面不是角色默认主页面本身不再构成错误。selected 材料在运行时先通过 page_targets 按录制的 origin/path 唯一解析目标，再将当前运行的 target_id 传给前置核对、导航及所有动作；零/多匹配或列表截断在写入前停止。显式“打开地址”也只操作解析到的所选页面。旧材料缺少选页证据时不补造证明，录制中跨到额外页面仍不支持。插入片段时给生成变量分配与草稿不冲突的名称，防止两份录制覆盖目标变量。

脱敏/截断/缺失值不能直接成为代码常量，更不能使用 [redacted] 作为真实值。输入值默认遮蔽，预览逐项选择绑定已有输入、保留完整非敏感录制常量或补充允许的值。敏感输入仅支持绑定已有输入，不新增默认值、不逆向恢复秘密；匹配采用 slot_id，不按字符串全局替换。绑定来自当前草稿 input_schema，检查类型与运行所需必填约束。

## 错误、兼容与影响

空/非录制材料、旧版证据不足、未停止/未保存、丢失截断、未知格式、源材料漂移、不可确定定位、缺失参数和不支持操作都给出可定位问题，提供前往上下文或使用 AI 编写的动作；不会自动切换为模型调用。生成失败保留当前代码及源材料。

录制补齐影响 contexts 采集持久化、Playwright 录制及相关消费者；生成影响插件 SDK/registry、authoring 与步骤代码页。保留所有既有工作区修改，实施前逐项核对这些文件当前状态。固定运行、其他十个插件、已有录制保存/ack 和 AI 编写默认行为保持兼容。

## 验收与验证

按[测试指南](../../testing.md)定向选择并维护 tests/module-map.json；全量测试仍需明确授权。

- 同一份已保存上下文可用于 AI 编写和本地生成，两者不消费/修改材料；本地生成不打开浏览器、不访问模型。
- 页面入口随草稿所选插件变化；无录制时引导上下文；选择材料、生成、问题/参数补充、完整预览、插入与替换接线正确。
- 真实录制验证 input/change 归并、控件切换边界、checkbox 去重、空字符串、单选 select、frame 和跨文档竞态；最终序号和持久化后 ack 保持正确。
- 旧版记录、缺口、重复/冲突分页、dropped_count、截断值、脱敏值、无效定位和不支持事件均不能产生可应用的残缺流程。
- 同一材料/绑定/配置生成一致结果；不执行记录内文本，不把观察值当断言，不把起始摘要当完整导航地址。
- 素材及草稿变化、切换步骤、迟到响应与 AI 候选竞争均保护当前草稿；插入保留 return，替换需完整差异确认。
- 本地 fixture 上真实录制 → 保存 → 关闭浏览器 → 本地生成 → 新运行执行，验证可脱离原会话及起点/角色语义。该验证不能替代真实业务网站或跨平台验收。
- 实施后的实际定向验证与平台限制记录在实施计划，不将本地 fixture 扩称真实业务验收。

## 审核与后续

本设计为唯一方案入口，替换上一版独立录制方案。用户已确认，按实施计划推进；现行知识按源码同步，验证目标维护在 tests/module-map.json。

重点审核：上下文统一录制与双生成出口；当前草稿的材料选择方式；既有旧录制的适用限制；录制语义补齐；默认继续已有页面与可选显式导航；本次仅转换可确定操作、业务断言由后续编写补齐。
