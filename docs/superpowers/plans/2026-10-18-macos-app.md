# TaskWeave macOS App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 在本机生成并安装可双击启动、包含全部 11 个插件、保留现有数据且能由 Codex 原生操作的 TaskWeave.app。

**Architecture:** 保留 NiceGUI/pywebview 与 Application，新增 macOS 冻结启动入口和 PyInstaller bundle。应用资源、构建环境、验收工作空间与用户工作空间分离；现有位置配置、实例锁及插件启用选择继续生效。

**Tech Stack:** Python 3.12、uv locked 环境、PyInstaller、NiceGUI、pywebview/WebKit、Playwright Chromium、macOS 原生控制接口。

**Spec:** [macOS 应用设计](../specs/2026-10-18-macos-app-design.md)

## Global Constraints

- 本次目标为 macOS Apple Silicon（arm64），不自动扩展为 Intel 或 Windows 验收。
- 全部插件 ID：playwright、ocr、tidb、utility、file、process、ssh、baota_dashboard、wordpress、uniapp、wechat_dev。
- 保留当前混合工作区，沿用用户要求的当前工作区；不创建工作树转移既有修改。
- 不改变数据库、任务包和插件协议；用户数据不进入应用 bundle。
- 不同步或替换当前自测虚拟环境；构建使用单独环境和现有 uv.lock。
- 保留已有 plugins.json；只有不存在该文件的全新工作空间初始化全部插件。
- 不下载依赖作为应用启动步骤；外部开发工具与远端目标沿用用户已有配置。
- 不强占现有工作空间，不终止未知进程，不执行既有业务流程。
- 不执行全量测试；不 commit、push、PR 或非本地发布。
- 计划与实现都在本会话完成；独立审核使用明确限定的改动清单，避免把其他未提交工作混入审核。

## Review Focus

1. Finder 启动缺少开发 PATH、PYTHONPATH 和当前目录：应用必须仍能打开并运行 worker；Task 2、3 实测覆盖。
2. 既有插件配置有禁用项或格式错误：原配置不得被覆盖，错误必须可见；Task 1 覆盖。
3. 冻结 worker 和日志窗口再次进入主程序：不得递归启动工作台；Task 1 单测及 Task 3 实测覆盖。
4. 旧服务占用数据或用户仍在录制：应用不得清理锁或另建空库冒充原数据；Task 1 锁冲突回归及 Task 4 接入前核对覆盖。
5. 插件 Python 导入成功但模型、动态库、浏览器或 Node 桥接文件缺失：Task 2 清单与 Task 3 真实本地动作覆盖；外部 Node/SDK 按插件配置显式报告。
