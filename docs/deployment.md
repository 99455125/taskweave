# 本地运行与交付

当前提供 Python 包安装与版本检查，无新 UI、后台服务、数据库和可执行安装包。

未来面向每个开发者本地运行，Windows 虚拟机为主要场景，macOS 可用于研发。Python 3.10+ 是新工程基线；旧分支的 Python 3.7 兼容注释不等于新包兼容承诺。

当前核心无第三方运行依赖。未来插件单独声明依赖，浏览器二进制和离线依赖按目标 Windows/Python 环境准备。打包方案另立需求。

本地目录约定为 `config/local.*` 与 `.runtime/`，仅为保留位置，当前未实现配置读取。不会自动读取或迁移旧 `EXCEL_BASE_DIR`。旧数据迁移需先备份并单独设计。
