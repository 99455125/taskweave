# AI 编写、对话与模型请求

来源：[Authoring](../../src/taskweave/application/authoring.py)、[公共提示词](../../src/taskweave/application/prompts.py)、[请求大小](../../src/taskweave/application/ai_requests.py)、[模型适配](../../src/taskweave/infrastructure/model.py)。产品内编写与研发文档协作是独立流程。

## 生成与采纳

步骤描述、编写说明、可执行内容分别保存。生成目的 purpose 为 content 或 repair；未传时按反馈/修复说明/历史选项兼容推导。先保存当前草稿，再组织任务变量名、步骤 schema/绑定、所选能力、插件贡献和采集证据；返回候选，经本地语法/权限/schema/插件 lint 检查及差异预览后由用户采纳。差异由程序 difflib 产生，不由模型编造。未采纳不等于更新步骤，更不等于验证成功。

无模型时可以手写、用动作表单插入代码、调试及确认。插件选择按整个插件，保存为明确动作列表；插件新增动作不会偷偷扩大旧步骤权限，需重新保存并验证。新增步骤默认继承末尾步骤插件，首步默认无选择。

API 模型走 Chat Completions：适配器声明 tools=true、images=false、json_object=true、json_schema=false。工具 wire 名用别名映射稳定动作 ID。网页 Chat 导出文本，不提供本机工具调用；粘贴整段回复可从 JSON/围栏及周边文本中提取合法步骤对象，推荐返回 step_content 与 explanation。兼容tool_calls=null。空回复、截断回复或缺步骤内容不能当作成功。连接测试实际调用模型并检查 async run，不能代表业务步骤正确。

公共协议、领域规则、插件贡献按层组合；渠道覆盖仅改变 instructions/examples，不放宽能力。未授权动作可作一次纠正，仍不合法就报具体错误；模型内容JSON无效最多纠正一次；接口返回非JSON不作为模型格式错误重试。HTTP状态、网络/代理、TLS、超时与响应格式分别报错，不把服务端原文/密钥作为错误提示。模型工具循环最多8轮，单工具30秒、会话180秒；HTTP单次45秒、回复最多2MiB。工具只用于允许的观察，WRITE须用户发起试跑。DeepSeek专有请求设置只对对应域名生效；其他兼容服务沿用标准协议。

## 历史与容量

每次可选择0轮、最近1–10轮或-1全部；未传 history_rounds 时，use_history=true取全部，否则0。对话保存在服务内存，重启清空，不是任务持久化版本。网页未采纳的导出不追加历史，采纳回合才记录。

“去除重复静态字段”只省略旧轮中由本轮重供的目标、源码、schema、变量清单；反馈、日志、采集上下文和AI回复仍保留。不能为适应容量静默减少用户所选轮数、删页面证据或压缩能力目录。该保证的已知失败测试仍在 [当前状态](../status.md)，不因文档迁移声称已修复。

本地限制按序列化UTF-8字节计量，默认2048KiB，设置整数1–4096KiB，保存在workbench.json；已有用户设置不覆盖。它不是token额度，模型服务自身上下文限制仍独立存在。API按最终请求body核算，网页按实际导出文本核算；超限提示调整选择，不自行丢历史。旧64/128KiB说明不再是默认契约。

## 调试修复

失败修复提供当前步骤、原描述、用户补充说明、最近尝试错误与有限日志（最多50条/16KiB），不会发送整个服务日志。可刷新当前保留页面，分别标记失败证据和当前观察时间；资源丢失明确提示，不自动导航或重建浏览器。

从首步调试若失败在前置步骤，先提示切换到该步，不能用前置错误修复当前步。采纳保存草稿并留在当前标签；后续调试读取最新内容。AI/debug共享同一trials映射，异步结果校验任务、步骤、运行及页面代次，迟到结果不改新目标。

## 模型与隐私

设置使用完整接口URL、模型名、API Key或环境变量引用。密钥本地保存、TLS及启动规则见 [API与配置](api-and-configuration.md)。请求提供变量名与引用规则，密钥值不作为推荐示例；实际脱敏按用户独立AI开关，不能保证任意自由文本秘密都可识别。

模型请求/回复会进入服务日志，敏感字段、已知密钥和Authorization做保护，不输出隐藏思考。上下文items和views分离、原始证据保留，详见 [采集协议](contexts.md)。当前模型不支持图像输入，不能把用户可见截图预览说成模型已经看过图片。
