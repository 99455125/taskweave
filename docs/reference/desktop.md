# 桌面交互与组件维护

来源：[Workbench](../../src/taskweave/desktop/workbench.py)、[页面](../../src/taskweave/desktop/pages)、[组件](../../src/taskweave/desktop/components)、[表单](../../src/taskweave/desktop/forms.py)、[显示](../../src/taskweave/desktop/display.py)。这是现行交互约束；历史截图不是布局规范。

## 页面与编辑

规划、任务、执行及环境/插件/设置等通过外壳导航。执行是独立入口，不把旧任务内三栏或五标签方案重新引入。步骤编辑“步骤详情/动作表单/输入依赖/时间设置”四个标签与右侧调试抽屉分工，内容/AI、参数依赖和配置读同一草稿；准确标签以StepEditor.render为准。

任务删除在任务列表，配置弹窗只编辑保存；重新打开配置读取最新任务。任务列表支持复制、排序、JSON分享及清理运行。步骤列表的添加/上下移动/删除操作固定，列表可滚动；重排仍需校验依赖。离页保留既有“继续编辑/舍弃修改并离开”确认，不能统一改成无条件自动保存。保存期间串行化，取锁后读取最新expected_hash；失败保持草稿，导航不能绕过保存失败。

“确认验证并保存”有当前有效成功调试证据时确认，否则询问手动验证；取消保留草稿。MANUAL和TRIAL证据分开，手动不伪造执行成功。切环境不自动撤销步骤确认，既有运行仍检验定义一致性。

## 调试、输入与执行

调试反馈展示环境变量、任务变量、步骤变量与依赖：环境只读，任务和未绑定步骤字段可作本次输入，不改默认值；绑定字段展示来源/样例。环境切换允许暂存未完成JSON和空必填草稿，提交严格校验。切换有保留资源的环境先确认结束，不能跨环境复用页面。

执行调试、从首步开始、结束调试和AI修复集中在反馈上方，API/网页渠道由统一AI入口选择。独立调试弹窗使用自己所选环境，并同步反馈页后续调试输入。三类变量分组默认展开需要补录的部分；已有值/默认值显示，未配置留空并给提示。

每次正式执行一行，步骤横向滚动，操作在右侧，详情只建在选中执行内部；收起/切换删除原容器，避免隐藏实例重复轮询。新建只建记录，执行到缺必填值时才补录。首步可联合提交任务/步骤输入；InputRequested按请求ID去重，取消保持暂停可重开。提交后即使离页也继续原运行模式/目标，随后不更新新页面。

成功步骤可从指定起点重跑到目标；前缀必须成功。删除执行须确认，仅清理该run，忙碌先结束；保留资源的完成run删除时释放。结束提示插件声明的资源，成功历史不变。人工核对选择实际业务结果，说明可选。结果按钮展示指定有效尝试/历史尝试的已存结果，见 [结果协议](persistence-results.md)。

## 状态与异步所有权

Workbench拥有外壳、路由、全局busy及装配；StepEditor拥有task/step/old_step、view和save_lock；Debug拥有运行、反馈、timer；AI拥有候选及预览；ContextPanel拥有采集草稿；ExecutionDetails拥有详情筛选/timer；Planning拥有规划表单/草稿/生命周期。禁止传任意host来访问所有状态。

每次await前捕获task/step/run/页面代次，回来核对；dispose释放本组件timer/绑定/view，不结束后台任务。UI容器和业务DebugPanel不能同名覆盖；AI/debug共用的空trials字典也须保持同一对象。同步回调不盲目await，fallback先清容器再调用factory。按钮busy/finally恢复是通用职责，调试状态变化用显式回调。

mark_step_pending/refresh_trial_inputs归StepEditor，enter_debug/settle_trial_start归DebugSession，补录校验与续启归RunInputDialog。组件单测要点实际入口，不只验证方法存在；接线变化选择现有真实浏览器流程。

## 显示、日志与设置

普通按钮白底蓝字、描边；优先/选中浅青色，失败/删除浅红或红色；相邻操作横排、窄窗换行。显示名称优先定义快照/可读标签，但不能为显示而改写业务UUID或结果内容。长日志自动换行，内容可选择。

服务日志按钮打开独立原生日志窗口，浏览器模式新标签；支持级别筛选、暂停、清空显示、打开日志目录，最近2000行。home/logs/server.log达5MB轮转一份，关闭日志窗不结束任务，服务退出回收日志窗。记录服务logging和AI正文，保护密钥及Authorization；worker业务日志仍在运行/调试详情。不承诺捕获所有stdout/stderr。旧复制/下载日志按钮不再是现行要求。

模型、隐私、默认环境、容量和工作空间迁移见 [配置](api-and-configuration.md)，连续采集见 [上下文](contexts.md)。
