# 工程规范（按需参考）

默认开工规则见 [AGENTS.md](../AGENTS.md)，本页补充工程约束，不要求每轮重读。

- 使用 src/taskweave 包布局；导入模块不能自动启动服务或改数据库。
- 遵守 [当前架构](architecture.md)；不为未确定功能添加空抽象或新框架。
- 接口、步骤/任务包、插件和数据库契约以现行源码为准；变更同步受影响模块并记录本次兼容策略，不要求回写其他历史 REQ。
- 插件独立声明依赖；缺依赖须明确报错，不隐式用 AI 或其他能力替代。
- 定义与运行分离；副作用、重试、恢复与 UNKNOWN 语义须明确。
- 配置与运行产物保存在本地；示例不包含真实账号、登录态或业务文件。
- 修改行为补充能发现真实回归的测试；文档调整仅结构/引用验证。数据库变化先设计迁移与恢复。
