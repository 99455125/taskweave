# 后续产品范围

本页保留尚未实现或尚未验收的产品知识，不自动启动任务。当前进行中事项仅见 [状态](status.md)。规划编写已有实现；它不等于运行时AI自主规划。旧编号先后顺序不再是今天必须按序执行的指令。

## 分享与离线分发

已有taskweave-task-2 JSON任务导入导出和复制，契约见 [任务分享](reference/task-sharing.md)。待设计/验收的是版本化zip manifest与资源清单、导出预览、明确ID冲突策略、显式更新覆盖与环境/角色映射、可选离线wheel、Python/OS依赖兼容及敏感内容剔除。

允许模型的环境与受限执行环境之间，完整的草稿/依赖与用户筛选脱敏feedback包协议仍需明确；现有JSON任务包和网页Chat不能代替完整离线反馈交接验收。

模板导入与安装插件分开，只启用受信任插件；不自动安装未知来源，也不实现在线市场。默认分享不含运行库、登录态与产物；现有源码/默认值/上下文可包含敏感值，因此“自动无凭据分享”仍是验收目标。显式覆盖不得覆盖活跃运行配置，历史保持。

验收必须在独立home往返绑定/上下文；缺插件或版本冲突列明解决项；损坏资源/zip越界路径拒绝且不覆盖原任务；分享包检查凭据及绝对路径；匹配Windows/Python的离线依赖实际验证。便携目标不允许安装，不能把开发机离线wheel验证当该目标验收。基础线性分享无需等待控制流；后者新增格式须自行升级兼容。

Windows10 x64完整便携构建工程已有，离线免安装目标实机验收尚未完成，见 [Windows交付](windows-portable.md)。需真实验证浏览器/截图/下载/角色隔离、停止/恢复、备份/升级、中文空格路径与权限，不能用macOS或fixture替代。macOS Intel/Apple Silicon分别构建验证，签名/公证/最低版本按实际产物记录；Linux不属于当前首轮桌面验收。

## 条件、循环与子流程

尚未实现，当前仍为线性任务。拟采用结构化节点，不允许任意连线形成隐式循环：

- 条件使用受限比较和明确默认分支，不执行任意代码表达式。真/假结果确定，缺失输入不静默走默认分支；未选中分支显示未选中而非失败。
- 循环显式集合或条件、迭代变量、最大次数和超时；初版顺序，集合在运行开始冻结。零次/多次/上限及失败可追溯，失败默认停止，重试不重复已确认副作用。
- 子任务按ID引用，输入输出显式映射，拒绝不存在引用、循环引用与递归。参数隔离、输出可回传。
- 以节点路径、迭代序号、子运行ID定位。单步、暂停、退出恢复继续同一迭代，UNKNOWN不自动重试；能进入子流程查看。

实施须同时覆盖持久化升级、旧线性任务兼容、导入导出及基础运行回归。不能仅加模型字段即宣称交付。

## 流程图编辑

依赖稳定控制流模型，先用交互原型验证组件，不预选库。拖拽已验证步骤、能力及控制流节点；参数面板展示输入、前序输出、分支/循环/子任务配置。布局坐标单独保存，图形和列表编辑使用同一执行模型，worker仍执行实际浏览器动作。

保存前定位断开节点、非法端口/引用/环路、缺少分支出口和未验证内容。验收图形保存重开语义/布局一致、列表往返不丢参数或稳定ID、活跃运行不可覆盖、运行高亮及迭代/子流程定位、结果日志跳转；新增定义分享和旧格式迁移也需验证。

## 候选而非承诺

多实例并发已有1–8池容量，后续系统级资源配额/排队仍需独立定义。定时调度与无人值守、运行时模型解析/提取/判断、AI动态选择动作或调整执行路线、在线插件市场与远程协作均未纳入当前固定执行交付。AI辅助编写/调试固化已有，不以运行时接入模型为前提。Excel仍不是核心或当前基础交付的必需插件。
